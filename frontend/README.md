# Anointed Hands - Frontend

React TypeScript frontend for the Anointed Hands booking and café management platform.

## Setup

```bash
npm install
```

## Development

```bash
npm start
```

Frontend will run on `http://localhost:3000`

## Build

```bash
npm build
```

## Environment Variables

Create a `.env` file in the frontend directory:

```
REACT_APP_API_URL=http://localhost:5000/api
```

## Features

- Services & menu browsing
- Appointment booking with calendar
- In-salon order form
- Admin dashboard for managing bookings and orders
- Manual EFT payment marking
- Real-time status updates
